# Support

Use [GitHub issues](https://github.com/PolaronQuasi/podvigil-modal/issues) for reproducible bugs and
questions. Include the package and Python versions, operating system, command, expected behavior and
a sanitized error. Never attach tokens or a complete private ledger.

A local test passing does not prove live provider availability or billing. Inspect retained
resources in Modal and follow [Operations](docs/OPERATIONS.md). Report sensitive issues through
[Security](SECURITY.md).
